# 首版实现与验收记录

日期：2026-11-05。本文对应设计的阶段 1–4；设计中的“后续专项适配”保持原边界。

## 设计落实

| 设计项       | 实现位置与行为                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| 本地文件集合 | `src/core/files.ts` 保留目录、中文/空格路径、相对资源关系；支持拖放文件夹、ZIP、多主文件选择           |
| 安全边界     | 1 GiB 输入/解压限制、ZIP 条目限制、越界和重复路径检查；阻止外部模型资源 URL，不启用模型持久化          |
| 适配器       | `src/adapters/registry.ts` 独立登记输入、输出、内容类型、实验性质及限制；导出适配器具有实际写入接口    |
| 中间数据     | 场景、点云、高斯、瓦片分开；动画保持 Three.js 场景通道，原始双精度点坐标和高斯数组独立于预览           |
| 队列         | `src/hooks/useTasks.ts` 一次运行一个任务，其余本机排队；可取消、失败重试、移除与连续导入               |
| 后台计算     | 带任务 ID 的 Worker 消息；取消终止并重建 Worker，结果数组转移所有权；重型模块按需加载                  |
| 预览         | OrbitControls、适配、线框、网格、全屏、动画播放/片段选择；点云局部原点与预览降采样；Spark 高斯形状预览 |
| 导出与报告   | 模型文件、ZIP、转换报告、对象关联属性；报告记录源与结果规模、参数、单位/方向变换、损失、耗时与文件名   |
| 地理坐标     | 父子矩阵、B3DM/PNTS RTC、量化 PNTS；最细分支选择、外部 tileset 引用、分块输出；单级封装写入有效包围体  |
| 发布         | 资源随站点分发、仓库子路径、生产 Worker/WASM 验证、GitHub Actions Pages                                |

`src/workers/engine.worker.ts` 处理 OBJ/STL、PLY、PCD、XYZ、LAS/LAZ、SPZ、CAD/IFC、采样、密度/距离场与 FBX 编码。需要 DOM 纹理/XML 和完整动画上下文的场景读取/导出在主线程异步编排，其同步库阶段无法提供精确百分比；取消后丢弃结果并释放资源。

## 格式路线

常用和广覆盖网格输入由锁定版本 Three.js 加载器读取。STEP/IGES/BREP 采用 OCCT；IFC 采用 Web-IFC；3DM 采用 Rhino WASM；FCStd 安全解压后提取已保存 BREP、可见性、对象属性和分组。未执行模型中的宏、脚本、外部 URL。

OBJ 输出真实 MTL 与 PNG 配套贴图、UV、法线、对象和材质组。PLY 网格输出双精度坐标、法线、UV、顶点颜色与三角面。STL/OFF 及 3DM 的材质/动画限制在界面和报告列出。glTF 输出内嵌缓冲/图像；无需外部 `.bin` 才能打开。

FBX 采用 Assimp 带导出的固定提交，经过 GLB 场景通道后编码。运行时检查文件内容签名，并用 FBXLoader 回读几何范围、面数、骨骼、蒙皮数量、动画数量与时长；不满足检查时拒绝下载。此路线仍为实验性，PBR 与软件特有属性可能降级。

点云 PLY 读取所有顶点标量；PCD 包含 ASCII、交错二进制、LZF 字段分组二进制；XYZ 采用三列坐标或六列坐标/RGB（0–255）。LAS/LAZ 限制版本 1.0–1.3、点记录 0–3。LAZ 兼容算法处理 LASzip 连续及分块压缩，v1/v2 属性项；与独立 LAS 参考比较。LAS 当前提取坐标、颜色、强度、分类，未声称提取全部 VLR/GPS/回波/波形数据。

高斯 PLY 根据标准尺度、四元数、透明度、基础球谐属性检测，保留所有已读取标量。SPLAT 使用真实 32 字节记录。SPZ v2/v3 通过 Spark 扩展精度解码并提取最高三阶球谐；记录源量化损失。球谐旋转在 Worker 中使用标准实球谐积分矩阵，同步保持方向相关颜色。

## 实验路线与质量

| 路线      | 算法与参数                                                             | 输出和限制                                              |
| --------- | ---------------------------------------------------------------------- | ------------------------------------------------------- |
| 网格→点云 | 三角面积分布采样，平方根重参数化；100–200 万点                         | 原始 UV 基础色贴图、材质色、顶点色；不烘焙光照/法线贴图 |
| 网格→高斯 | 表面采样、切平面尺度与法线方向四元数、基础球谐与透明度                 | 不训练新外观，不恢复源模型没有的信息                    |
| 点云→网格 | 空间网格邻域、局部协方差法线、径向初始定向、有符号距离场、四面体等值面 | 凹面/开口、噪声和稀疏区域可能产生错误表面；不保证封闭   |
| 高斯→网格 | 各向异性旋转高斯密度累积、可调阈值、四面体等值面                       | 三倍标准差支持域；近似密度外壳，不是物理表面            |
| 高斯→点云 | 中心坐标与基础色提取                                                   | 高斯形状、透明度、视角相关属性不进入普通点云            |

重建分辨率 `16³–96³`，默认 `32³`；超过 30 万点时均匀步进选取参与点并记录实际数量；网格超过 200 万三角面时要求降低分辨率。源数据未被预览/重建的降采样替换。

## 保留与透明降级

- 导出副本应用变换，不累计修改源模型。源单位未知时由用户设置；glTF 通道统一换算为米。
- 网格双精度原始位置与渲染位置分开保留，大坐标采用局部原点；支持的文本/PLY/3DM 路线保留相应精度，STL/glTF 本身存在字段精度限制。
- IFC 构件表达式 ID、基本属性、属性集、类型属性及空间结构保留；DotBIM GUID/属性、OCCT 面区间与装配、FreeCAD/Rhino 可提取属性进入场景或侧车文件。
- `metadata.json` 不能代替目标格式的原生工程语义。无法读取的字段明确列出，不写“无损成功”。
- PLY 非顶点/面的附加元素、顶点列表与面附加属性未提取；凹多边形建议预先三角化。格式损坏、版本不支持或无几何时给出错误，不生成伪结果。
- 没有地理定位时保持局部坐标，不推断 CRS 或经纬度。单级 Tiles 用节点变换保持原数值坐标，并保存局部轴说明，不生成 LOD 金字塔。

## 自动化验证

- 单元测试：ZIP/路径边界、中文目录、三类 PLY、PCD/SPLAT、双精度、球面重建误差、单高斯理论密度球、三阶球谐旋转外观与逆变换。
- 浏览器测试：所有公开输出路线回读；GLB/glTF/FBX 蒙皮动画、材质、UV/贴图；CAD/FreeCAD 真实样例；IFC/DotBIM 属性；SPZ v2/v3、LAS 版本和真实 LAZ 对照；瓦片矩阵/RTC/最细 LOD；重建所有目标；外部资源零请求、取消及独立重试。
- 交互测试：禁用无输入转换、示例导入、真实下载、ZIP 完整包、390 px 移动布局。
- 发布测试：生产产物严格挂载 `/model-converter/`，检查本地 Worker、WASM、动态模块、下载和资源网络边界。
- 桌面 Chrome、Edge、Firefox 均实际运行；CI 在 Chromium/Firefox 重复验证。样例来源和许可在 `tests/fixtures/README.md` 以及各第三方样例目录中记录。

1 GiB 上限和低分辨率降级不代表所有设备都能成功处理上限文件；不对任意输入版本、扩展或任意内容互转作保证。当前支持以实际适配器与验收样例为准。
